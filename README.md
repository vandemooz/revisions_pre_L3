# revisions_pre_L3
L'objectif de ce projet est de réviser l'ensemble des langages de programmation et fonctionnalités apprises en 2ème année de *Licence Professionnelle - Métiers de l'Informatique* afin d'être à niveau pour la 3ème année.

Le programme se déroule sur les 6 semaines à venir et est partagé en **4 grands moments** :

1. **Révisions HTML / CSS / Responsive design**
2. **Révisions JavaScript (Vanilla et jQuery)**
3. **Révisions PHP + Twig + Gestion de base de données (MySQL / PDO)**
4. **Docker + Intégration + Projet final**
